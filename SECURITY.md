# Security

F99 Mood asks for sensitive permissions (Input Monitoring, Accessibility and
audio recording), so security problems matter even in a small app.

## Reporting a problem

Please don't open a public issue for a security problem. Instead, report it
privately through GitHub:
[Report a vulnerability](https://github.com/papihaj/aula-f99-mood/security/advisories/new).

Include what you found, how to reproduce it and which version of F99 Mood and
macOS you used. You'll get a reply within a week. Once a fix is released, the
advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release gets fixes. Update with the install command or the
download link in the [README](README.md#how-to-install).
